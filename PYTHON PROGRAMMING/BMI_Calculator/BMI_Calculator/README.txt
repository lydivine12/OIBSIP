BMI Calculator

How to run:
1. Open this folder in VS Code.
2. Make sure Python is installed.
3. Open the terminal.
4. Run:

python bmi_calculator.py

This is the simplified GUI version of the BMI Calculator.

BMI formula:
BMI = weight / (height²)

Categories:
Underweight: BMI < 18.5
Normal: 18.5 - 24.9
Overweight: 25 - 29.9
Obese: BMI >= 30
